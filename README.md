# C++ 学习与交流

这里用于整理和分享 C++ 学习过程中的代码、解题思路与实践记录，涵盖基础语法、算法、数据结构和课程作业。

希望通过具体的代码，把知识点、实现思路和遇到的问题记录下来，也为正在学习 C++ 的朋友提供一份可以阅读、讨论和共同完善的参考。

仓库目前处于起步阶段，已建立分类目录，后续将逐步补充代码与说明。欢迎提出问题、指出不足，也欢迎分享不同的实现方法。

## 内容与目录

```text
cpp-code/
├── basics/              # C++ 基础练习
├── algorithms/          # 算法
│   ├── sorting/         # 排序算法
│   └── searching/       # 查找算法
├── data-structures/     # 数据结构
└── coursework/          # 课程作业
```

- **基础练习**：用于整理语法、输入输出、函数、指针、类与标准库等知识点的练习。
- **算法**：按主题整理算法实现与解题思路，便于比较不同方法的特点。
- **数据结构**：用于记录链表、栈、队列、树、图等数据结构的实现与应用。
- **课程作业**：按课程和作业主题归档代码，结合题目记录分析过程与学习总结。

## 阅读与运行

可以从感兴趣的目录开始阅读，结合代码注释和目录中的说明理解实现思路。

各练习通常作为独立程序组织；如果多个文件分别包含 `main()`，请分别编译运行。涉及多个源文件、特定 C++ 标准或第三方依赖的内容，应参考对应目录中的说明配置环境。

## 交流与贡献

欢迎通过 [Issues](https://github.com/zheng-2526/cpp-code/issues) 提出问题、反馈错误或讨论思路，也欢迎通过 Pull Request 补充代码、改进实现和完善说明。

分享代码或提出改进时，建议：

- 将内容放在对应的分类目录，使用清晰的文件名。
- 简要说明题目或用途、实现思路，以及必要的编译和运行条件。
- 反馈问题时，附上相关代码位置、输入示例、实际结果与预期结果，方便复现和讨论。
- 提交源代码与必要的说明文件，避免加入可执行文件和其他编译产物。

欢迎围绕代码交流，在讨论与实践中一起进步。
